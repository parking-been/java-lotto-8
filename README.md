# java-lotto-precourse

# 🪙 로또

---

## 기능 요구 사항

간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

# 🗃️ 역할 분리

---
### [controller]
- **로또 controller**
    - 하는 것 :
        - 발행한 로또 수량 및 번호 출력
        - 당첨 내역 출력
        - 수익률 출력

### [domain]
- **로또 service**
    - 하는 것 :
        - 로또 중간 비지니스 구현 
          - 로또 발행
          - 당첨 번호 및 보너스 번호 설정
          - 당첨 내역 계산
          - 수익률 계산
- **로또 - Lotto**
    - 아는 것 : 발행한 로또 번호
- **순위 - Rank**
  - 아는 것 : 각 순위 당 규칙, 상금 저장 
- **로또 repository - LottoRespository**
    - 아는 것 : 발행한 로또들의 정보
    - 하는 것 : 로또 정보 관리
- **로또 발매기 - LottoGenerator** 
    - 하는 것 : 입력 값을 받아 로또를 만들어냄
- **당첨 번호 - WinningLotto**
    - 아는 것 : 당첨 번호
    - 하는 것 : 발행한 로또 번호를 입력하면 얼마나 매칭되었는지 알려줌
- **당첨 결과** - LottoResult
    - 아는것 : 당첨 내역 결과
    - 하는 것 : Rank에 해당되는 당첨 결과 저장

### [view]
- InputView
  - 사용자에게 입력값을 받음
- OutputView
  - 결과를 출력함

# ✒️ 구현할 기능 목록

---

목표 : 간단한 로또 발매기를 구현한다.

### [준비]

- 로또 구입 금액을 입력 받는다.
    - parser를 사용하여 입력 문자열 → 정수 형태로 바꿔준다.
        - 정수로 바꾸지 못할 경우 예외처리한다.
- 당첨 번호를 입력 받는다.
    - parser를 사용하여 입력 문자열 → `,`를 기준으로 구분하여 정수 list형태로 바꿔준다.
        - 정수로 바꾸지 못할 경우 예외처리한다.
- 보너스 번호를 입력 받는다.
    - parser를 사용하여 입력 문자열 → 정수 형태로 바꿔준다.
        - 정수로 바꾸지 못할 경우 예외처리한다.

- 위에서 받은 정보를 바탕으로 로또 repository (LottoRepository), 당첨번호(WinningLotto)를 setting한다.
    - 로또 repository setting 하기.
        - 로또 발매기(LottoGenerator)에 구입 금액을 입력한다.
            - 구입 금액이 1000원 단위가 아니라면 예외처리한다.
            - random 정수를 출력하는 메소드를 사용하여 정수 6개를 반환한다.
            - 해당 정수들을 받아 구입 금액에 맞는 로또들을 생성한다.
        - 생성된 로또 번호들을 로또 repository에 저장한다.
    - 당첨 번호 setting 하기.
        - 당첨번호에 입력받은 당첨 번호와 보너스 번호를 입력한다
            - 이때 입력 받은 번호가 1~45 사이가 아니라면 예외처리한다.
            - 입력 받은 당첨 번호 사이 중복이 있으면 예외처리한다.
            - 보너스 번호가 당첨 번호에 포함되어있으면 예외처리한다.
        - 당첨 번호를 저장한다.
- 로또 service는 로또 repository(LottoRepository)와 당첨번호(WinningLotto)를 관리한다.

### [진행]

진행의 큰 단위는 controller가 맡는다.

- 발행한 로또 수량 및 번호 출력 
    - 로또 정보를 받아 OutputView에서 출력한다.
- 당첨 내역 계산
  - LottoRepository와 WinningLotto를 사용하여 당첨 내역(LottoResult)결과를 업데이트 한다.
    - Rank에 담긴 순위 기준을 바탕으로 당첨 내역결과를 업데이트 한다.
- 당첨 내역 출력
    - 당첨 내역 결과를 outputview에서 출력한다.
- 수익률 출력
    - 당첨 결과에서 수익률을 계산하도록 한다
        - 소수점 둘째 자리에서 반올림한다
    - outputview에서 수익률을 출력하도록 만든다.
