# java-lotto-precourse

# 🪙 로또

---

## 기능 요구 사항

간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

# 🗃️ 역할 분리

---

- **로또 controller**
    - 하는 것 :
        - 발행한 로또 수량 및 번호 출력
        - 당첨 내역 출력
        - 수익률 출력
- **로또 service**
    - 하는 것 :
        - 로또 중간 비지니스 구현 (추후 구체화)
          - ..
        - 로또 service는 크게 로또 repository, 당첨 결과 계산기로 구성되어있다.
- **로또 - Lotto**
    - 아는 것 : 발행한 로또 번호를 담고 있다
- **로또 repository - LottoRespository**
    - 아는 것 : 발행한 로또들의 정보
    - 로또들을 관리하는 곳
- **로또 발매기** - interface 가능 - LottoGenerator
    - 하는 거 : 로또를 만들어낸다.
        - random 형식으로 만들어낸다.
- **당첨 번호 - WinningLotto**
    - 아는 것 : 당첨 번호
    - 하는 것 : 로또 번호를 주면 얼마나 매칭되었는지 알려준다.
- **당첨 결과 계산기 - LottoResultCalculator**
    - 아는것 : 당첨 내역 결과
    - 하는 것 :
        - 당첨 여부 계산기에서 받은 정보로 당첨 결과 저장함
        - 수익률을 계산함
- **당첨 내역 결과 - LottoResult**

# ✒️ 구현할 기능 목록

---

목표 : 간단한 로또 발매기를 구현한다.

### [준비]

- 로또 구입 금액을 입력 받는다.
    - parser를 사용하여 입력 문자열 →(trim)→ 정수 형태로 바꿔준다
        - 정수로 바꾸지 못할 경우 예외처리한다.
- 당첨 번호를 입력 받는다
    - parser를 사용하여 입력 문자열 → (trim) → `,`를 기준으로 구분하여 정수 list형태로 바꿔준다.
        - 정수로 바꾸지 못할 경우 예외처리한다.
- 보너스 번호를 입력 받는다.
    - parser를 사용하여 입력 문자열 → 정수 형태로 바꿔준다.
        - 정수로 바꾸지 못할 경우 예외처리한다.

- 위에서 받은 정보를 바탕으로 로또 repository (로또), 당첨번호를 setting한다
    - 로또 repository
        - 로또 발매기에 구입 금액을 입력한다
            - 구입 금액이 1000원 단위가 아니라면 예외처리한다
            - random 정수를 출력하는 메소드를 사용하여 정수 6개를 반환한다
            - 해당 정수들을 받아 로또를 생성한다
        - 생성된 로또 번호들을 바탕으로 로또 repository를 생성한다.
    - 당첨 번호
        - 당첨번호에 입력받은 당첨 번호와 보너스 번호를 입력한다
            - 이때 입력 받은 번호가 1~45 사이가 아니라면 예외처리한다.
        - 당첨 번호를 생성한다
    - 로또 service는 로또 repository와 당첨 결과 계산기를 관리한다


### [진행]

진행의 큰 단위는 controller가 맡는다

- 발행한 로또 수량 및 번호 출력
    - 로또 repository에게 dto형식으로(?) 로또 정보를 받는다
    - outputview에서 출력하도록 만든다.
- 당첨 내역 출력
    - 당첨 여부 계산기에게 로또 정보를 전달하여 당첨 내역을 만들어낸다
        - 당첨 여부 계산기 내부에는 당첨 번호가 있어서 이를 바탕으로 계산한다.
    - outputview에서 출력하도록 만든다
- 수익률 출력
    - 당첨 결과에서 수익률을 계산하도록 한다
        - 소수점 둘째 자리에서 반올림한다
    - outputview에서 수익률을 출력하도록 만든다.
